# Code of conduct

This project is for people learning and teaching ideas, so be the kind of collaborator you'd
want in a classroom:

- Be kind and assume good faith. Critique the work, not the person.
- Welcome newcomers. Questions that seem basic are how everyone starts.
- No harassment, insults, or discriminatory language, in issues, PRs or anywhere else in the
  project.
- Credit other people's work, and quote sources accurately.

The maintainer may edit or remove comments, and block people who break these rules. To report
a problem privately, open a
[private security advisory](https://github.com/standard-librarian/lambda-factori/security/advisories/new)
titled "Conduct".
